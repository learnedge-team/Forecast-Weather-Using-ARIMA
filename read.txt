# Weather Forecasting ARIMA Model Training Pipeline Documentation

This document provides comprehensive documentation for the Python script designed to train an ARIMA model for daily temperature forecasting using historical weather data.

## 1. Overview

This pipeline automates the process of downloading a weather dataset, preprocessing it, training an optimal ARIMA (AutoRegressive Integrated Moving Average) model for temperature prediction, evaluating its performance, and saving the trained model and relevant artifacts for future use. The goal is to provide a robust framework for time series forecasting.

## 2. Pipeline Steps

The `main()` function orchestrates the entire process through several well-defined steps:

### Step 1: `download_dataset()`
- **Purpose**: Downloads the `muthuj7/weather-dataset` from Kaggle. This ensures that the script always works with the specified data source.
- **Output**: Returns the local path where the dataset files are downloaded.

### Step 2: `load_and_explore_data(path)`
- **Purpose**: Loads the weather dataset from the provided path (identifying the CSV file within the downloaded directory) and performs initial data exploration.
- **Exploration Includes**: Displaying dataset shape, column names, first 5 rows, data types, missing values, and basic statistical summaries.
- **Output**: A Pandas DataFrame containing the raw weather data.

### Step 3: `preprocess_data(df)`
- **Purpose**: Cleans and transforms the raw DataFrame into a format suitable for time series modeling.
- **Key Operations**:
    - **Column Identification**: Dynamically identifies 'date' and 'temperature' columns based on keywords.
    - **Date Parsing**: Converts the date column to UTC datetime objects and sets it as the DataFrame index.
    - **Timezone Removal**: Removes timezone information from the index for consistency.
    - **Missing Value Handling**: Drops rows with invalid dates and handles missing temperature values by resampling and filling (forward-fill then back-fill).
    - **Duplicate Index Removal**: Ensures unique time steps in the index.
    - **Resampling**: Aggregates hourly data to daily averages for temperature. This reduces noise and computational load.
    - **Feature Extraction**: Extracts additional weather-related features (Humidity, Wind Speed, Pressure, Visibility, Apparent Temperature) and resamples them to daily averages.
- **Output**: Two Pandas DataFrames: `ts_daily` (daily temperature time series) and `additional_features` (daily averages of other weather metrics).

### Step 4-6: `train_arima_model(ts_daily)`
- **Purpose**: Trains and evaluates an ARIMA model.
- **Key Operations**:
    - **Data Truncation**: Optionally uses the last 2 years of data for training if the dataset is very large, to manage computational time.
    - **Train-Test Split**: Divides the data into 85% for training and 15% for testing.
    - **ARIMA Parameter Search**: Iterates through a predefined grid of `(p, d, q)` orders to find the best ARIMA model based on the Akaike Information Criterion (AIC). The parameters `p_values = [0, 1, 2, 3, 5]`, `d_values = [0, 1, 2]`, `q_values = [0, 1, 2, 3]` are explored.
    - **Model Training**: Fits an ARIMA model to the training data using the best-found order.
    - **Evaluation**: Forecasts values for the test set and calculates key performance metrics: Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and Mean Absolute Percentage Error (MAPE).
    - **Retraining on Full Data**: After identifying the best order, the model is retrained on the entire `ts_train_data` (either last 2 years or full dataset) to maximize the use of available historical information.
- **Output**: Returns the final fitted ARIMA model, its best order, evaluation metrics, and the historical data used for training.

### Step 7: `save_artifacts(model, order, metrics, ts_data, additional_features)`
- **Purpose**: Persists the trained model and relevant data artifacts to disk.
- **Key Operations**:
    - **Serialization**: Uses Python's `pickle` module to save the fitted ARIMA model, its optimal order, evaluation metrics, historical temperature data, and additional weather features into a single `.pkl` file (`weather_arima_model.pkl`).
    - **Separate Data Save**: Also saves the historical temperature and additional features data separately in `historical_weather_data.pkl` for easier access.
    - **Verification**: Loads the saved model and performs a small forecast to confirm its integrity.
- **Output**: The saved `weather_arima_model.pkl` and `historical_weather_data.pkl` files.

## 4. Model Details: ARIMA (p, d, q)

ARIMA models are characterized by three parameters:
- **p (Autoregressive order)**: The number of lagged observations in the model. This accounts for the relationship between the current observation and a number of preceding observations.
- **d (Differencing order)**: The number of times the raw observations are differenced to make the time series stationary. A stationary time series has statistical properties that do not change over time (e.g., constant mean, variance).
- **q (Moving Average order)**: The size of the moving average window, representing the dependency between an observation and a residual error from a moving average model applied to lagged observations.

The pipeline systematically searches for the optimal combination of these parameters based on the AIC, which balances model fit and complexity.

## 5. Performance Metrics

- **MAE (Mean Absolute Error)**: The average of the absolute differences between actual and predicted values. It gives a direct measure of the average magnitude of the errors.
- **RMSE (Root Mean Squared Error)**: The square root of the average of the squared differences between actual and predicted values. It gives more weight to larger errors, making it sensitive to outliers.
- **MAPE (Mean Absolute Percentage Error)**: The average of the absolute percentage errors. It provides a percentage error measure, which can be useful for interpretation, especially when comparing models across different scales.

A Streamlit dashboard for daily temperature forecasting using an ARIMA model trained on the Muthuj7 weather dataset (Kaggle). This repository includes training and inference code, model artifacts, and interactive visualizations.

Features
- Train an ARIMA model and save artifacts (`trainmodel.py`).
- Interactive Streamlit dashboard (`app.py`) with:
  - Forecast generation (configurable days)
  - Historical analysis and monthly/yearly views
  - Model evaluation (MAE/RMSE/MAPE, residuals)
  - Data downloads (forecast & historical)
- Additional weather feature plotting if available (humidity, wind speed, pressure)

Quickstart
1. Create a virtual environment and install dependencies:

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

2. Train the model (downloads dataset via kagglehub and saves artifacts):

```bash
python trainmodel.py
```

This creates `weather_arima_model.pkl` and `historical_weather_data.pkl` in the repo folder.

3. Run the Streamlit dashboard:

```bash
streamlit run app.py
```

Files
- `app.py` — Streamlit dashboard.
- `trainmodel.py` — Training pipeline: download, preprocess, train ARIMA, save artifacts.
- `weather_arima_model.pkl` — Saved model and artifacts produced by training.
- `historical_weather_data.pkl` — Saved historical data snapshot.
- `requirements.txt` — Python dependencies.

Notes & Troubleshooting
- If the dataset download fails, ensure you have Kaggle credentials or change `trainmodel.py` to use a local CSV.
- If Streamlit reports deprecation warnings, update calls to `st.plotly_chart(..., width='stretch')` and `st.dataframe(..., width='stretch')` (already applied in this repo).
